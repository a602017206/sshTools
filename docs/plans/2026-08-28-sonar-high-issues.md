# Sonar 高优先级问题修复计划

**目标：** 在不改变 SSH、SFTP、数据库和桌面界面对外行为的前提下，消除 `sonar-high-issues.csv` 中列出的 50 条问题。

**策略：** 本次清单以认知复杂度、重复字面量和空实现说明为主，未包含可直接利用的安全缺陷。重构仅通过提取无副作用辅助函数、定义私有常量和补充说明完成；不调整协议、持久化格式、错误码或 UI 交互。

**技术栈：** Go、Svelte/JavaScript、Java/Spring、Go testing、Gradle。

## 执行步骤

1. 为各受影响 Go 服务先补充或复用行为回归测试，并在修改前运行以建立基线。
2. 先处理不影响运行路径的规则：重复字面量、空函数说明和 `dataset` 写法。
3. 对 JavaScript 的高复杂度函数，提取纯计算或菜单构建辅助函数，保持输入输出不变。
4. 对 Go 的高复杂度服务函数，按既有错误处理顺序拆成私有步骤；每个文件完成后运行所属包测试。
5. 对 SSH 管理器和 SFTP 传输路径进行单独回归验证，确认并发、取消和进度事件语义不变。
6. 运行 Go 全量测试、JDBC Agent 定向测试、前端构建与静态检查，并重新执行 Sonar 扫描验证余项。

## 验收标准

- CSV 中的规则不再出现在 Sonar 扫描结果中，或仅保留经确认无法安全重构的项并记录理由。
- 现有 Go 与 JDBC Agent 定向测试通过，前端构建成功。
- 不修改当前工作区已有的 `frontend/build/` 和 `frontend/wailsjs/` 生成文件。
