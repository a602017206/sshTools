# 运维工作区 UI 分阶段重构 — 设计规格

> 状态：三期实现已落地（双模式壳 + 数据库打磨 + 会话标签/上传视觉）  
> 实现计划：`docs/plans/2026-08-10-ops-workspace-ui-redesign.md`  
> 关联：`docs/designs/2026-08-05-unified-ops-workspace.md`  
> 日期：2026-08-10  
> 原型参考：亮色 SSH 工作台 / 数据库模式高保真稿（会话内确认）

## 1. 背景

sshTools 已具备 SSH 终端、SFTP、监控与数据库能力。初版「多工作区标签」把文件、性能与终端平级，造成割裂；概览页价值低。用户确认：

- 去掉概览；
- **SSH 会话**与**数据库**拆成两个主模式；
- 文件 / 性能绑定当前 SSH 会话（右侧工具坞），不做顶栏平级页；
- 视觉以**亮色、克制、专业工具感**为主（像正式产品设计，而非模板后台）。

## 2. 目标与非目标

### 目标

- 顶栏一眼分清「在 SSH」还是「在数据库」。
- SSH 下终端为主舞台；文件 / 性能是会话工具，切换会话时跟随。
- 数据库模式专注对象树 + 查询 / 表数据，不出现文件坞。
- 亮色为默认观感基准；深色保留但服从同一结构，不做两套布局。
- 不破坏现有连接、会话、SFTP、数据库 bindings。

### 非目标

- 不重写 Go / Wails API。
- 不实现 Docker / 日志后端。
- 不做营销向概览大盘、假指标卡片。
- 不引入新状态管理框架。

## 3. 信息架构（修订）

```text
顶栏：sshTools | [ SSH 会话 | 数据库 ] | 新建连接 · 主题 · 设置 · 开发工具

SSH 会话模式
├─ 左：资源树（SSH / 数据库资产仍可列出，点 SSH 在此模式连接）
├─ 中：会话标签 + 终端（主舞台）
└─ 右：会话工具坞
   ├─ 分段：文件 | 性能
   └─ 标题注明「绑定 · {当前会话名}」
   无 SSH 会话 → 坞内空状态「先连接一台主机」

数据库模式
├─ 左：资源树 / 已连接对象树
├─ 中：数据库会话标签 + 列表 / 查询 / 表数据 / 表设计
└─ 右：可选结构检查器（无文件 / 性能坞）
```

**导航规则**

| 用户动作 | 落点 |
|---|---|
| 连接 SSH | 进入 SSH 模式，打开终端会话 |
| 连接数据库 | 进入数据库模式，打开库面板 |
| 点顶栏「数据库」 | 仅切换模式；不卸载 SSH 会话（TerminalPanel 常驻或等价保活） |
| 点顶栏「SSH 会话」 | 回到终端工作台；工具坞仍绑当前 SSH 会话 |

**删除的顶栏项：** 概览、文件、性能、Docker、日志（作为平级工作区）。

## 4. 视觉系统（修订：亮色专业工具）

对标克制的桌面生产力软件：细线、轻阴影、少装饰、青绿点缀。

| Token | 用途 | 亮色（主） | 深色（从） |
|---|---|---|---|
| Canvas | 窗体底 | `#F7F8FA` | `#09111e` |
| Surface | 面板 | `#FFFFFF` | `#101d31` |
| Hairline | 分割线 | `#E6EAF0` | `#22314a` |
| Ink | 主文字 | `#0F172A` | `#e6edf7` |
| Mute | 次文字 | `#64748B` | `#9aa8bd` |
| Accent | 主操作 / 选中 | `#0E7490` | `#39d5e8` |
| Accent soft | 选中浅底 | `rgba(14,116,144,0.08)` | `rgba(57,213,232,0.12)` |
| OK / Warn / Bad | 状态 | `#168f68` / `#b45309` / `#e05266` | `#70d6ab` / `#f0b865` / `#fb7185` |

**造型**

- 顶栏高约 48px；主模式用**分段控件**（pill），不用一排过多文字标签。
- 圆角约 10px；阴影单层、很轻；禁止多层霓虹 glow。
- 图标一律 SVG；状态必须有文字（已连接 / 断开）。
- 等宽字体仅用于终端、SQL、遥测数字。
- 动效：150–250ms 的边框/背景过渡；`prefers-reduced-motion` 下关闭。
- 记忆点：分段控件选中态的细青绿条 + 工具坞「绑定 · 会话名」微标题（体现会话绑定，而非炫光）。

**明确不做：** 紫色营销风、奶油衬线、报纸密排、概览大数字假盘、emoji 图标。

## 5. 分阶段实现（修订）

### 第一期：双模式壳 + 亮色专业皮

- `workspaceTabs` 改为两主模式：`ssh` | `database`（内部可保留 files/performance 为 SSH 坞内 tab，不再是顶栏）。
- `App.svelte`：顶栏分段控件；去掉 OpsDashboard 作为默认首页；默认进入 SSH 模式。
- TerminalPanel 在模式切换时保持挂载（或 SSH/DB 会话状态不丢）。
- 右侧坞：文件 | 性能 分段；标题显示绑定会话。
- 全局 token 按亮色表收紧 `app.css`。

### 第二期：数据库模式打磨

- 数据库空状态、错误短句、`运行 / 保存 / 断开` 文案统一。
- 数据库模式下隐藏文件/性能坞；可选结构侧栏。

### 第三期：SSH 工具坞体验

- 无会话空状态；切会话时文件/监控跟随。
- 会话标签文字状态；上传进度纳入同一视觉系统。
- 收尾文档与回归。

## 6. 架构与数据流

```text
App.svelte
  activeMode: 'ssh' | 'database'
  sshToolTab: 'files' | 'performance'   // 仅 SSH 模式 UI
  → assetsStore / connectionsStore / activeSessionIdStore（不变）
  → TerminalPanel 常驻（SSH 终端会话 + 数据库 panelType 会话）
  → FileManager / ServerMonitor 仅在 SSH 模式右侧坞中显示
```

连接落点：`workspaceForAsset` → SSH 资产进 `ssh`，数据库资产进 `database`。

## 7. 错误与空状态

| 场景 | 表现 |
|---|---|
| SSH 模式无会话 | 中区引导连接；工具坞「先连接一台主机」 |
| 数据库模式无库会话 | 空状态：从资源树连接 / 新建数据库连接 |
| 连接失败 | 短中文原因 + console 详错；少用整段 `alert` 堆栈 |

## 8. 测试策略

- 扩展 `workspaceTabs` 测试：主模式解析、资产落点、坞内 tab 与顶栏分离。
- 每期 `npm run build`；手工：SSH↔数据库来回切不丢会话；SFTP/监控随会话；DB 查询回归。

## 9. 风险

- 模式切换若卸载 TerminalPanel 会丢会话 → **常驻挂载**硬约束。
- 数据库会话与 SSH 会话同在 TerminalPanel 时，坞只应响应 SSH 类型活动会话 → 活动会话为数据库时，坞显示「当前不是 SSH 会话」或自动定位最近 SSH 会话（实现时选一种并写死，推荐：坞绑定「最近一个已连接的 SSH 会话」，不随 DB 标签误绑）。
