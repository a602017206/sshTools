# 变更：发布说明补充近期功能

## 背景

自动发布工作流的更新说明未覆盖近期完成的终端快捷键、连接克隆与 SFTP 拖放上传功能，且发布时间使用不适用于标签推送触发流程的 release 事件字段。

## 范围

- 更新 `.github/workflows/release.yml` 的发布说明。
- 记录 2026 年 08 月 13 日的功能、修复和体验优化内容。

## 修改文件

- `.github/workflows/release.yml`

## 验证

- 检查 YAML 缩进与 GitHub Actions 表达式语法。
- 执行 `git diff --check`。

## 剩余风险

- 发布说明中的日期为本次更新日期；后续发版需要按实际版本内容与日期同步更新。
