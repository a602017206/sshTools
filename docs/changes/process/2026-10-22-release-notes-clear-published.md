# 清空已发布的 Release 更新说明预填

## 背景

`.github/workflows/release.yml` 的发布说明正文在 v0.0.24 发版前预填了 1 条新增、3 条修复、2 条优化。v0.0.24 已于 2026-10-22 正式发布，这些条目若保留，下一个版本会自动带上重复内容。

## 范围

- 清空「更新内容」下已发布的全部条目，仅保留「新增功能 / 修复问题 / 优化体验」三个空分类标题，供下一版本从头填写。
- 「下载说明」（桌面与移动端安装指引）为长期说明，完整保留。

## 修改文件

- `.github/workflows/release.yml`
- `docs/changes/process/2026-10-22-release-notes-clear-published.md`（本文）

## 验证

- 检查 release.yml 中 body 结构未破坏：版本、时间、分类标题、下载说明各段完整。

## 剩余风险

- 下一版本发版前需按实际变更补填条目；留空分类标题会在发布说明里显示为空小节，发版前留意清理或补填。
