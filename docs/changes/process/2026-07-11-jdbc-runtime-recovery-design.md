# JDBC 运行时恢复设计记录

## 背景

JDBC 管理后续开发需要补齐运行时选择持久化、启动恢复、状态自动刷新和内置日志查看。为避免配置位置、切换失败语义和日志读取边界在实现阶段反复变化，先形成独立设计文档。

## 范围

- 明确运行时设置继续使用现有应用配置文件。
- 明确切换后立即重启 Agent，以及持久化失败和重启失败的回滚边界。
- 明确状态轮询生命周期和固定日志尾部读取限制。
- 明确后端、前端、桌面和工具链验证要求。

- 检查新增和修改的文档正文均使用中文。

## 剩余风险
