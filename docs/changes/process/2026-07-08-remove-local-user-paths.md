# Process Change: Remove Local User Paths

## Background

The repository is intended for public release. Some tracked files and newly added documentation contained local user-specific absolute paths, which should not be published.

## Scope

Removed local user path literals from publishable code, scripts, and documentation. Replacements use relative paths, `$(pwd)`, `PATH`, or configurable environment variables.

After a follow-up scan, Flutter local generated files under `flutter_ui/` were also sanitized so local full-directory scans no longer expose the user path.

- `go.mod`
- `docs/audits/2026-07-08-codebase-scan.md`
- `docs/changes/bugs/2026-07-08-config-fallback-save.md`

- `docs/changes/process/2026-07-08-documentation-governance.md`
- `docs/archive/FRONTEND_NEW_COMPLETE.md`
- `docs/archive/FRONTEND_NEW_IMPLEMENTATION.md`
- `flutter_ui/MACOS_SETUP.md`
- `flutter_ui/run_macos.sh`
- `flutter_ui/CONNECTION_UI_IMPLEMENTATION.md`
- ignored local Flutter/IDE generated files under `flutter_ui/`

## Verification

- Scanned tracked and non-ignored files for the local user path literal; no matches remained.
- Scanned all files under `flutter_ui/`, including ignored generated files, for the local user path and username; no matches remained.
- `GOCACHE="$(pwd)/.cache/go-build" go test ./...` passed.
- `GOCACHE="$(pwd)/.cache/go-build" go vet ./...` passed.

## Residual Risks

- Ignored Flutter generated files can be regenerated by Flutter tooling and may later contain local paths again; they remain excluded from version control.
