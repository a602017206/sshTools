# 数据库对象分类独立加载

## 背景

右侧数据库对象列表并发读取表、视图、存储过程和函数。任意一个分类失败时，原实现会让整个页面显示“加载数据库对象失败”，导致表也不可见。

## 范围

将对象加载改为独立结算。成功分类继续显示对象；失败分类仅在自身区域显示具体错误信息。

## 修改文件

- `frontend/src/components/SelectedDatabaseObjects.svelte`
- `frontend/build/assets/index.js`
- 本变更记录。

## 验证

执行 `npm run build`，前端编译和 JDBC agent 暂存均通过。

## 剩余风险

未连接真实 MySQL 实例复现特定例程元数据错误。失败原因现在会显示在对应分类中，便于后续根据实际驱动或权限错误继续定位。
