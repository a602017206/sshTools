# 变更：数据库连接行展开箭头不可见

## 背景

侧栏数据库连接行应有展开/收起箭头，用于展开库表树。视觉重构后箭头使用绝对定位且默认 `opacity-0`（仅悬停显示），又与新增状态灯重叠，导致用户看不到下箭头。

## 范围

- 仅修复 `AssetList` 数据库连接行的展开控件可见性与布局顺序。

## 修改文件

- `frontend/src/components/AssetList.svelte`

## 验证

- 打开含数据库连接的分组：连接名前左侧应常显向右箭头；展开后变为向下箭头。
- 状态灯仍在箭头右侧，不遮挡。
- 点击箭头可展开/收起，不触发整行连接。

## 剩余风险

- 无。
