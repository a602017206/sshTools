# 数据表结果网格列宽调整

## 背景

数据表查询结果使用 `minmax(150px, 1fr)` 生成自动列轨道。在只返回少量字段时，最后一列会填满整个可用区域，即使字段名和单元格内容很短也会显得过宽。同时，页面没有提供调整列宽的操作入口，影响数据浏览效率。

## 范围

- 将数据结果网格改为按字段计算的固定像素列宽，保留横向滚动。
- 在表头右边界增加拖拽调整柄，支持用户调整单列宽度。
- 保留表头中的数据类型、长度和描述信息；初始宽度不以字段声明长度或描述文本撑开。

## 修改文件

- `frontend/src/lib/tableGridColumns.js`
- `frontend/src/components/DatabaseTablePanel.svelte`
- `frontend/test/tableGridColumns.test.js`

## 验证

- 使用 Node 测试验证初始宽度、固定网格轨道和拖拽宽度边界。
- 执行前端生产构建，确认 Svelte 组件可以编译。

## 剩余风险

- 当前列宽只在已打开的数据表标签页内保存，切换或重新打开标签页后会恢复为按字段计算的默认宽度。
