# 顶栏新增明暗主题快速切换

## 类型

功能优化

## 需求

用户反馈明暗主题切换放在设置弹窗里操作别扭，希望直接放到右上角，并与设置按钮平级。

## 实现

- 在主界面顶栏新增明暗主题切换按钮。
- 当前暗色模式显示太阳图标，点击切换到亮色；当前亮色模式显示月亮图标，点击切换到暗色。
- 抽取 `persistAppSettings` 复用全局设置持久化逻辑，快速切换后同步写入后端设置。
- 保留全局设置里的系统跟随和外观细项配置。

## 验证

- 已执行 `cd frontend && npm run build`，通过；仍存在项目既有 Svelte a11y 和 chunk size 警告。
- 已执行 `GOCACHE="$(pwd)/.cache/go-build" go test ./...`，通过。
- 已执行 `GOCACHE="$(pwd)/.cache/go-build" go vet ./...`，通过。
