# 应用 Logo 终端文案更新

## 背景

应用 Logo 顶部包含“啊哈”文字，而终端屏幕中仅显示提示符。现将 Logo 调整为更直接的终端品牌表达。

## 范围

- 移除顶部“啊哈”文字。
- 将终端屏幕字符更新为 `>_ aha`。
- 保留原有的蓝绿立体终端、USB 插头和线缆视觉风格。

## 修改文件

- `build/appicon.png`

## 验证

- 检查输出为 1024 × 1024 的 PNG 图标。
- 人工检查顶部不再包含中文文字，终端内显示 `>_ aha`。

## 剩余风险

- Windows 的 `build/windows/icon.ico` 与 Flutter 客户端各平台图标未在本次同步更新；使用这些独立资源构建时仍会显示原图标。
