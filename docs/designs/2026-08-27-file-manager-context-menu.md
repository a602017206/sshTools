# 文件管理右键菜单

## 背景

文件列表现有右键菜单只有打开、下载、重命名、复制路径和删除。用户需要接近常见 SSH 客户端的文件操作菜单：顶部快捷图标、刷新、收藏路径、上传下载、以及更多里的新建和改权限。

## 目标与范围

在文件管理面板内用绝对定位弹出菜单，覆盖文件行和空白处右键。本次接通已有或可安全补齐的 SFTP 操作，不实现缺少后端的能力。

包含：

- 顶部图标：重命名、粘贴、剪切、复制
- 打开 / 本地打开、刷新
- 收藏或取消收藏当前路径（复用目录历史）
- 下载至、选择文件上传
- 重命名、删除
- 更多：复制路径、新建文件夹、新建文件、修改权限

不包含：在线编辑、选择文件夹上传、SCP 传输、压缩、解压缩。这些需要独立的编辑器、递归上传或远程命令，不在本次范围。

复制仅支持文件；剪切可作用于文件和文件夹（远程重命名）。粘贴到同目录时，复制会自动加 `copy` 后缀。

## 架构与取舍

菜单模型放在 `fileManagerContextMenu.js`，与 Svelte 组件分离，便于单测定位、快捷键和权限转换。原生窗口裁切问题沿用现有方案：菜单相对文件管理面板 `absolute` 定位，而不是视口 `fixed`。

新建文件、远程复制和 chmod 补到现有 SFTP 客户端，不引入新协议。权限输入使用八进制字符串（如 `644`），避免在 UI 里做复杂的 rwx 矩阵。

## 风险

部分 SFTP 服务器对 `O_EXCL` 创建或 `chmod` 支持不完整，失败会显示后端错误。目录复制尚未支持，复制文件夹时按钮禁用。
