# 连接克隆与新增表单重置设计

## 背景

连接编辑后再新建连接时，新增表单可能继续显示上一条连接的填写内容，导致用户误保存错误配置。同时，复用相近连接只能手动重复填写，缺少快捷的克隆入口。

## 目标

新增连接始终从空白默认表单开始；右键连接可打开克隆表单，保留可复用配置并提供唯一、可编辑的默认名称。

## 方案

将连接表单的默认值和克隆数据转换提取为纯函数。打开“新增”时明确传入空白模式，打开“克隆”时明确传入源资产；克隆模式不复用源连接 ID，不加载或保存源连接密码，并以“原名称 copy YYYYMMDDHHmmss”预填名称。右键菜单由 `AssetList` 提供入口，`App` 统一控制对话框模式。

## 取舍

克隆仅复制非敏感配置（类型、主机、端口、用户名、认证类型、密钥路径、分组和数据库元数据），不复制密码、私钥口令和已保存的凭据。这样既减少重复录入，也避免将秘密意外扩散到新的连接记录。

## 风险

时间戳以本地时间生成，同一秒内重复执行会得到相同名称，但连接 ID 仍唯一；用户也可在保存前修改名称。
