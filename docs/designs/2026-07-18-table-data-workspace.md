# 表数据工作区设计

## 背景

现有表数据页以大面积 SQL 文本框为中心，数据表格只是下方结果区域，不能满足持续浏览表数据的工作流，也与 Navicat 类数据库客户端的对象数据页风格不一致。

## 目标

将表数据页改为数据网格优先的工作区。用户打开表后应立即看到行号、列标题、数据行、筛选和固定状态栏；SQL 编辑器在需要时通过模式切换展开，查询历史和对象上下文固定在右侧。

## 方案

- 顶部显示当前表、数据库和 Schema，并提供“数据 / SQL”模式。
- 工具栏使用紧凑图标按钮执行 SQL、重新加载默认 100 条、清空结果和打开 SQL 编辑器。
- 网格采用固定行号列、可排序列标题、单元格选择状态以及滚动容器。
- 右侧显示表对象信息和可复用的查询历史；底部状态栏显示返回行数和当前单元格值。
- 保留已有 `LIMIT 100` 默认查询、手写 SQL、列排序、结果筛选和错误提示。

## 风险

当前后端结果协议只返回列与行，不包含主键、字段类型、行状态或分页游标。因此该版本不提供行内编辑、提交、删除和服务端分页，避免界面呈现无法可靠执行的操作。
