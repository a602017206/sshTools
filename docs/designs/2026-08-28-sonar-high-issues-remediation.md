# Sonar 高优先级问题修复设计

## 背景

SonarQube 对项目报告了 50 条高优先级问题。规则主要为 `S3776`（认知复杂度）、`S1192`（重复字面量）、`S1186`（空实现）及 JavaScript DOM 写法建议；它们影响维护性和审计可读性，但 CSV 未报告注入、认证绕过或敏感数据泄露等直接安全漏洞。

## 取舍

采用小粒度、语义保持的重构：提取私有辅助函数，保持原有控制流、错误文案、事件名和返回值不变。不会为了降低复杂度重写 SSH 协议、连接生命周期、数据库查询或前端菜单行为。

不调整 Sonar 规则阈值，也不通过 `NOSONAR` 压制问题；这会隐藏问题而非改善可维护性。

## 边界

本次不修改现有前端构建产物和 Wails 自动生成绑定文件。所有源代码改动都以对应包的测试或最小回归测试验证。
