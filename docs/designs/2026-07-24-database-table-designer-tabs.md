# 数据库表设计器标签页设计

## 背景

表结构设计器此前在应用右侧面板中显示，与文件管理和服务器监控争用有限空间，无法提供符合数据库客户端习惯的完整编辑工作区。

## 设计

- “设计表”与对象树发出的表结构事件均打开主工作区标签页。
- 同一连接、数据库、Schema 和表的设计标签复用已有标签，避免重复加载同一结构。
- “新建表”每次创建独立标签，允许并行准备多个新表。
- 表数据、SQL 查询和表设计标签均引用原始数据库会话；关闭子标签只关闭前端标签，不关闭数据库连接。
- 右侧区域只保留文件管理和服务器监控，不再承载表设计器。

## 取舍

本次复用已有 `TableStructurePanel`，仅调整其宿主和会话路由，避免将字段编辑、DDL 预览和创建逻辑复制到新组件。既有表的 `ALTER TABLE` 能力仍按现有范围后续实现。
