# 设计：运维工作区 UI 分阶段重构

## 背景

用户反馈概览无必要；文件/性能与终端平级会造成割裂；希望 SSH 与数据库拆开，并采用更专业的亮色产品视觉。

## 决策摘要

- 顶栏仅 **SSH 会话 | 数据库** 二分模式。
- 文件 / 性能 = SSH 右侧会话工具坞（标明绑定会话），非顶栏页。
- 去掉概览及 Docker/日志平级工作区。
- 视觉：亮色专业工具（Canvas `#F7F8FA`、Accent `#0E7490`），克制细线与分段控件。
- 完整规格：`docs/superpowers/specs/2026-08-10-ops-workspace-ui-redesign-design.md`。
