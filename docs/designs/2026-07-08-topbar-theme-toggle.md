# 顶栏明暗主题切换设计

## 背景

明暗主题切换属于高频视觉操作，放在全局设置弹窗内层级过深，用户需要打开设置、定位主题模式、保存，操作成本偏高。

## 设计方案

- 将明暗切换入口提升到右上角顶栏，与上传任务、全局设置同级。
- 使用 32px 图标按钮，尺寸和设置按钮保持一致。
- 当前暗色主题显示太阳图标，点击切换到亮色；当前亮色主题显示月亮图标，点击切换到暗色。
- 点击后立即应用主题并持久化到后端设置。
- 顶栏按钮只负责快速切换亮色/暗色；系统跟随和更完整的外观配置仍保留在全局设置中。

## 交互约束

- 添加/编辑连接弹窗打开时，按钮跟随其他顶栏操作禁用。
- 按钮使用 `ops-icon-button`，继承当前主题的 hover、文字和边框 token。
