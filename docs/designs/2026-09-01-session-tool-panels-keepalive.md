# 设计：会话工具文件与性能面板保持挂载

## 背景

右侧「文件 / 性能」用 `{#if toolTab}` 互斥渲染。切走时 Svelte 销毁组件：`FileManager` 的当前路径、目录跟踪 Map 和 `ssh:cwd` 订阅丢失，再切回来会按家目录重载；`ServerMonitor` 的定时器和已采集曲线也被清掉，只能重新拉数，体感很慢。

## 决策

会话已绑定期间，两个面板始终挂载，用 `hidden` 只控制可见性。切换标签不再走 create/destroy。没有绑定会话时仍只显示空状态。

抽出 `sshToolPanelHidden(activeTab, panelId)`，避免模板里手写互斥条件。性能页在后台继续 2 秒轮询，这是「并行」的预期代价。

## 风险

隐藏的文件面板仍在听 CWD 事件；隐藏的监控仍占用一条 SSH 命令通道。断开会话时两边会一起卸载并清空状态，符合现有逻辑。
