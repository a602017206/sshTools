# 性能监控采集失败：SSH 会话未标记类型

## 背景

为拦截本地终端误跑远程命令，`ExecuteCommand` 要求会话 `Type == ssh`。但 `CreateSession` 创建远程会话时没有写入该类型，零值不是 `ssh`，性能页通过 SSH 执行 `hostname` / `top` / `free` 等采集命令会被全部拒绝。前端把失败当空数据，于是一直显示 0% 和 Unknown。

## 目标与范围

远程 SSH 会话创建时标记为 `ssh`；执行独立命令时，只要不是本地会话且存在 SSH Session，就允许采集。本地会话仍拒绝。不改监控 UI 和采集脚本。

## 风险

已打开的旧会话仍是零值类型；修复后需依赖「有 SSH Session 即可执行」。新连接会带上正确类型。
