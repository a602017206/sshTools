# 设计：会话日志记录与常用命令提示

## 背景

SSH 终端仅有实时 PTY I/O，缺少会话落盘与按连接的命令提示。路线图将「会话日志记录」列为核心增强；同时需要在键入时提示该服务器常用命令，支持 Tab/点击填入后再回车执行。

完整规格见：`docs/superpowers/specs/2026-09-04-session-log-and-command-suggest-design.md`。

## 决策

- **范围**：日志四项（自动记录、搜索导出、保留策略、敏感过滤）+ 常用命令提示 + `release.yml` 同步。
- **命令史**：按 `connectionId` 单独存储；回车时从前端当前输入行提取；不从会话日志反解析。
- **日志默认**：开启记录；保留 30 天；写入前脱敏；均可在设置中关闭或调整。
- **架构**：`SessionLogService` / `CommandHistoryService` 后端落盘；`Terminal.svelte` 负责行缓冲与浮层。
- **交互**：Tab/点击只填入，不自动执行；再回车执行。
- **目录跟踪**：仅将文件管理器 `DirectoryTracking` 默认改为 `true`，不覆盖用户已保存的关闭状态。

## 非目标

端口转发、跳板机、标签页快捷键、日志反解析命令、命令浮层独立「常去目录」实体。
