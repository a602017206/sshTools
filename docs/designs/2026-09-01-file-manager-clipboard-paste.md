# 文件管理 Ctrl+V 粘贴本地文件

## 背景

文件管理已有远程剪切/复制后的粘贴，以及按钮/拖放上传。用户需要在面板内用 Ctrl+V（macOS 为 Cmd+V）把系统剪贴板里的本地文件或文件夹上传到当前目录；若选中了一个文件夹，则上传到该文件夹内。必须沿用串行上传，禁止再按文件数扇出 goroutine。

## 目标与范围

- 焦点在文件管理时，主修饰键 + V：优先上传系统剪贴板中的本地路径
- 无本地路径时，仍执行原来的远程粘贴
- 恰好选中一个非 `..` 的文件夹时，目标为该文件夹；否则为当前目录
- 同一 SSH 会话上所有上传（粘贴、拖放、按钮）共用一把锁，同时只跑一棵目录树
- 剪贴板只返回顶层路径，展开与传输仍走已有 `ExpandUploadPaths` + 串行 `UploadItems`

不包含：从剪贴板粘贴文本成新文件、多选文件夹时拆分目标、独立 SFTP 连接。

## 架构

Go 按平台读取文件列表（Windows `CF_HDROP`，macOS 剪贴板文件 URL，Linux `text/uri-list`）。前端用纯函数决定目标路径，再调用现有冲突处理与串行上传。快捷键仍由 `matchFileManagerShortcut` 识别 `v`，避免在终端焦点时误伤 Ctrl+V。

## 风险

WKWebView 不会给出文件绝对路径，必须走原生剪贴板。超大目录展开仍可能短暂占用 UI，但 SSH 侧保持串行。
