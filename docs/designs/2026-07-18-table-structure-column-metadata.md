# 表结构字段元数据展示设计

## 背景

右侧表结构面板当前仅显示 DDL。用户无法直接查看字段的 JDBC 标准元数据，例如数据类型、长度和字段描述，且不同数据库驱动的能力没有统一展示入口。

## 目标

在所有使用 JDBC agent 的关系型数据库表结构面板中，在 DDL 前展示字段表头，包含字段名、数据类型、长度、描述、可空、主键和默认值。

## 方案

JDBC agent 继续以 `DatabaseMetaData.getColumns` 为唯一来源：已有类型、长度和默认值字段，新增读取标准 `REMARKS` 列作为描述。协议将描述传给 Go 服务，再由 Wails 绑定提供给 `TableStructurePanel`。

前端独立请求表结构 DDL 与字段元数据。DDL 的生成职责保持不变，字段表格直接使用结构化元数据，因此所有 JDBC 驱动遵循同一显示逻辑，无需在 Svelte 中判断 MySQL、PostgreSQL 或国产数据库类型。

## 边界与取舍

- `REMARKS` 依赖驱动和数据库权限；缺失时显示 `-`，不伪造注释。
- 非 JDBC 的原生 NoSQL 面板不使用关系型表结构组件，不纳入本次字段表展示范围。
- 字段长度由 `COLUMN_SIZE` 提供；对不适用的类型显示 `-`，小数位保持在数据类型文本中展示。
