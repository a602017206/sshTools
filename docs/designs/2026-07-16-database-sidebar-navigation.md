# 数据库左侧导航设计

## 背景

数据库对象层级此前渲染在主内容区，左侧连接列表只包含数据库和表，无法提供数据库客户端常见的统一资源导航。

## 目标

将连接、数据库、Schema 和对象分类放在左侧树中。右侧主内容区采用数据库客户端常见的单一对象浏览器：顶部分类切换当前对象类型，默认展示表；仅在用户切换到视图、存储过程或函数后加载并展示相应列表。右侧信息栏显示当前数据库和连接上下文。

## 方案

新增 `DatabaseSidebarTree`，在已连接的数据库资产下按需加载数据库、Schema、对象分类和对象名称。使用 `databaseNavigationStore` 保存按 JDBC 会话分隔的当前选中数据库；右侧 `SelectedDatabaseObjects` 订阅该状态，按当前分类延迟加载标准 JDBC 对象元数据。表项可以打开表结构。

## 风险

跨数据库浏览依赖当前 JDBC 会话和驱动对 catalog 的支持。部分驱动在连接到单一数据库时无法枚举其他数据库的 Schema，界面会显示元数据错误而不会影响当前连接。

对象行数、存储引擎、数据长度和创建时间需要额外统计查询，当前 JDBC 元数据协议不提供这些字段；首版仅展示可靠的对象名称和分类，不伪造统计信息。
