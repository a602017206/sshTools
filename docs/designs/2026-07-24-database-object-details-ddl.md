# 数据库对象详情栏 DDL 设计

## 背景

数据库对象页需要在不打开表设计标签页的情况下查看表信息与建表语句。现有详情栏宽度固定，且只显示字段摘要，无法适应不同字段名和 DDL 长度。

## 设计

- 对象详情栏提供“信息”和“DDL”两个模式按钮，同一时间只显示一个内容区域。
- 信息模式保留数据库信息和只读字段结构预览；DDL 模式展示当前选中表的建表语句。
- DDL 按需调用既有 `GetTableDDLInSchema` 或 `GetTableDDL` 接口。带 Schema 的数据库使用前者，其他数据库使用后者。
- 详情栏左缘提供拖拽分隔条，宽度限制在 220px 至 560px，避免挤压主列表或产生不可读的窄栏。
- 工具栏提供显示/隐藏查看栏按钮。隐藏不会清空当前选择，重新打开后可继续查看信息或 DDL。

## 取舍

DDL 不在对象页内编辑，避免将查询预览与独立表设计器的结构修改流程混合。表结构修改仍由独立标签页承担。
