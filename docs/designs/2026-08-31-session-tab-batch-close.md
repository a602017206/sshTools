# 会话标签批量关闭

## 背景

顶部会话标签只能逐个点关闭。连接一多，标签被挤窄，关闭按钮还要悬停才出现，无法一次清掉左侧、右侧或全部会话。

## 目标与范围

在当前模式可见的会话标签上增加右键菜单：

- 全部关闭
- 关闭左侧
- 关闭右侧
- 关闭其它

关闭范围以右键点中的标签为准，不要求先激活该标签。首尾标签上不可用的「关闭左侧 / 关闭右侧」禁用。仅一个标签时禁用「关闭其它」。

已连接的 SSH 会话批量关闭只弹一次确认；数据库标签仍与单击关闭一样不确认。不改后端会话协议。

## 架构与取舍

关闭范围计算放在 `sessionTabClose.js`，与标签栏组件分离，便于单测。实际关闭仍走现有 `closeSession` / `removeSession`，父数据库会话关闭时继续收起子面板。批量循环里跳过已不存在的会话，避免父会话级联删除后误调 `CloseSSH`。

## 风险

右键菜单使用视口坐标，靠近窗口边缘时可能被裁切。Map 中的会话顺序即标签顺序，与插入顺序一致。
